HOW IT WORKS
01

Upload

Select a PDF up to 20 MiB. It stays in memory and is discarded immediately after scoring.

02

Read bytes only

Extracts 658 static byte, entropy, and string statistics. The file is never opened, rendered, or run.

03

Score and explain

XGBoost produces a calibrated risk probability alongside exact TreeSHAP feature attributions.

04

Flag uncertain files

Scores in the 29%–55% review band or outside training size/string bounds are routed to manual review.

LIMITATIONS
  • Static features only: DocSentry does not execute scripts or render pages; it cannot observe runtime shellcode or parser memory corruption.
  • Heavy dependence on link counts: Link annotations (/URI) drive a large share of attribution. Link-heavy benign files face higher false alarms, while malicious PDFs without links have lower recall.
  • Small benign files get more false alarms: Benign files under 100 KB experience higher false-positive rates due to EMBER2024 training size distributions.
  • Probabilities are stepwise: Isotonic calibration is a step function; raw scores between 0.20 and 0.30 all display as 40.8% and route to manual review.
  • Never run on real malicious PDFs: The model was evaluated only on EMBER2024 feature data and this app has never been run on real malicious PDFs.
  • Not an antivirus replacement: Intended as a fast static triage pre-filter alongside dynamic sandboxing and endpoint protection.
