How to Interpret DocSentry Results

  • Three-State Triage: Files scoring < 29.0% are auto-passed as Benign. Files > 55.0% are flagged as likely malicious. Scores inside [29.0%, 55.0%] are escalated to Needs Manual Review.
  • Isotonic Calibration: Probabilities are calibrated on validation data. Under newer data they can be too optimistic, which is why a manual-review band exists.
  • SHAP Attribution: Shows the exact mathematical contribution (in log-odds margin) of each feature pushing the score toward malicious or benign.
  • No execution: the file is never opened, rendered or run: Only byte-level statistics, entropy distributions, and printable strings are extracted. The file is never interpreted or opened.

System Limitations & Honest Boundaries

  • Static Features Only: DocSentry does not execute JavaScript or render pages. It cannot observe runtime zero-day memory corruption shellcode.
  • Heavy Link (/URI) Dependence: Approximately 19.4% of total model attribution rests on link count indicators. Link-heavy benign files face elevated risk.
  • Sub-100 KB Benign Penalty: Small benign documents face a higher false-alarm rate (22.9x higher FPR, 5.65% vs 0.25% for ≥100 KB) due to EMBER2024 training size modes.
  • Stepwise Isotonic Probabilities: Calibrated probabilities are produced by monotonic step functions; raw model scores between 0.20 and 0.30 all map to a flat plateau at 40.8% (routed to manual review).
  • Not Tested on Real Malware: Evaluated strictly on the synthetic EMBER2024 static feature subset; not tested against live, zero-day malware binaries in the wild.
  • Not an Antivirus Replacement: Intended as a fast pre-filter and triage assistant, not a substitute for defense-in-depth dynamic sandboxing or signature-based AV.
